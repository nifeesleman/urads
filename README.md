# UrAds

UrAds is a modern, secure, two-sided marketplace connecting **Advertisers** and **Influencers**.  
The platform allows brands to create campaigns, receive applications from influencers, and manage payments using an **escrow-protected system**, while influencers can build profiles, showcase portfolios, and apply to campaigns.  

UrAds is designed to feel like a high-end SaaS platform, built with **modern web technologies**, and optimized for scalability and usability.

## Features

**For Advertisers:**

- Create, edit, and manage campaigns  
- View incoming applications and accept/reject influencers  
- Monitor campaign performance  

**For Influencers:**

- Build and edit profiles (bio, niches, platforms, portfolio)  
- Browse campaigns and submit applications  
- Receive notifications on application status  

**For Admins:**

- Manage users and campaigns  
- Monitor platform activity  

**General Features:**

- Real-time notifications for unread messages and pending applications  
- Secure escrow-protected payments  
- Responsive design for desktop and mobile  
- AI-powered discovery tools for campaign matching

## Technologies

UrAds is built using modern, high-performance web technologies:

- **React** – Frontend UI library  
- **TypeScript** – Type-safe development  
- **Vite** – Fast build tool and dev server  
- **Tailwind CSS** – Utility-first styling framework  
- **shadcn-ui** – Ready-to-use React component library  
- **Node.js & npm** – Backend dependencies management
